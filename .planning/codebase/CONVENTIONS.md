# Coding Conventions

**Analysis Date:** 2026-07-12

## Naming Patterns

**Files:** `snake_case.zig` (`main.zig`, `status_json.zig`, `bounded_str.zig`); `src/scripts/*.sh` for embedded shell.

**Functions:** snake_case (`applyStatusJson`, `resolveMole`, `spawnStatus`, `ensureThen`, `handleAuthDone`, `pickRootDisk`).

**Types:** PascalCase structs/enums — `Model`, `Msg`, `Tab`, `JobKind`, `SudoPhase`, `ProcessRow`, `HistoryRow`, `LogLine`.

**Variables:** snake_case fields; effect keys are `snake_case` module consts (`status_key`, `history_key`, `job_key`, `auth_key`, `ping_key`, `keepalive_timer_key`).

**Generics:** `BoundedStr(comptime n)` (`src/bounded_str.zig:5`).

## Code Style

**Formatting:** `zig fmt` (0.16) enforced by the pre-commit hook (`zig fmt --check` in `.pre-commit-config.yaml`). No other formatter.

**Linting:** none (no Clippy/Zig-equivalent configured).

## Import Organization

**Order:** `std` first, then `runner`, then `native_sdk`, then sibling modules (`src/main.zig:3-7`; `src/update.zig:3-7`).

## Error Handling

- No exceptions (Zig has none). Subprocess output is parsed defensively: `std.json.parseFromSlice(std.json.Value, ..., .{ .ignore_unknown_fields = true })` (`src/status_json.zig:10`, `:100`). Unknown fields are ignored so the parser survives Mole schema drift.
- `applyStatusJson`/`applyHistoryJson` return `!void`; callers `catch` into boolean + `BoundedStr` message flags (e.g. `src/effect_handlers.zig:15`, `:41`). The UI never sees the raw error.
- Embedded shell scripts are pulled in with `@embedFile` (`src/sudo.zig:12-13`), not read from disk at runtime.

## State conventions

- Single `Model` (`src/model.zig:204`). All string fields use `BoundedStr(n)` via `set`/`slice`/`orDefault`/`isEmpty` (`src/bounded_str.zig`); **`set` silently truncates** oversized input — by design for the TEA model; do not reintroduce parallel raw buffers.
- Error/busy state is modeled with explicit bools + a `BoundedStr` message. Do NOT reintroduce parallel sudo booleans (`sudo_active`, `sudo_auth_silent`, …) — use the `SudoPhase` enum (`src/model.zig:115`).

## Logging

**Framework:** in-app job log only (`Model.appendLog`, `src/model.zig:472`); no external logger. ANSI is stripped via `stripAnsi` (`src/model.zig:494`).

## Comments

Minimal, only for non-obvious intent (e.g. disk-root rationale `src/status_json.zig:134`, `SudoPhase` semantics). No doc-comment spam. Each module has a `//!` file-level header.

## Function Design

- `update` is generated by `makeUpdate(comptime Effects: type)` (`src/update.zig:57`) so effects are injectable/testable.
- Mutators live on `Model` (e.g. `setMolePath`, `appendLog`); keep new state logic there.
- Pure exit mutations live in `src/effect_handlers.zig` (no `Effects` dependency) so they unit-test without spawning.

## Module Design

- `main.zig` is wiring only (re-exports, `initialModel`, `app_markup`, `Loop`). Add logic to the matching module, not back into `main.zig`.
